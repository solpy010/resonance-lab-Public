## 기본 흐름

1. 상단 **씬 프리셋**에서 시작(1_2 징 파일럿 등) 또는 빈 프로젝트 + 레이어 추가
2. **해상도**: 3840×640 / 4096×420(벽면 9.74:1) / 3508×2160(1면) / 사용자 지정. **면 수**는 가이드·반응 위치 기준(A~F)
3. **배경**: 단색(색상 슬라이더 H/S/V·HEX) · 블랙 · 크로마(그린/블루/사용자) · 투명(알파)
   - 발광·반투명 요소를 크로마로 뽑으면 가장자리 번짐 경고가 뜹니다 → 투명 또는 블랙 권장
4. **마커**: 오디오 불러오기 → 대역(전체/저음/고음)·감도 조정 → 「타격 검출 → 마커」, 또는 BPM 그리드, 재생 중 `T` 탭, 타임라인 더블클릭
5. 레이어 「마커 반응」에서 반응 위치(모든 면 / 한 면 / 한 면→인접면 전파 / 지정 면 / 무작위)와 면 간 지연 설정
6. **키프레임**: 파라미터 옆 ◇ 클릭 = 현재 시간에 키 추가/삭제(◆), Alt+클릭 = 그 항목 키 전체 삭제. 이징은 Quint Out
7. **검수 보기**: 흑백 · 10% 축소 · 글로우 끄기 · 면 가이드 · 체커보드
8. **렌더 / 출력**: PNG 시퀀스(투명 배경이면 RGBA 알파) 또는 MP4(H.264). 항상 0프레임부터 100% 해상도로 다시 계산

## v0.5.3 — 리듬선 너울 춤 · 면 고무줄 너울+컬러 흐름 · 레이어 복사/붙여넣기

### 라인 › 리듬선: 「너울 춤 (BPM)」 (기본)
날카롭게 꺾이며 위아래로 떨던 구버전 대신, 부드러운 물결 언덕이 박자에 맞춰 부풀고 좌우로 너울거리며 흘러갑니다. 구버전은 `리듬선 움직임 → 면별 진동(구버전)`으로 계속 쓸 수 있습니다.
- `BPM` · `물결 언덕 수` · `흐름 속도(언덕/박자)` · `박자 부풂` · `그루브(좌우 흔들림)` · `모양 변화`·`주기` · `언덕 모양(사인↔종)` · `언덕에서 선 벌어짐`
- 선 수를 10~20개로 늘리고 선 간격을 좁히면(0.01 안팎) 여러 가닥이 한 묶음으로 춤추며 언덕에서 부채처럼 벌어집니다. 두께 1~2px, 밝기 0.5 안팎 권장.

### 면 › 세로 면: 「고무줄 너울 + 컬러 흐름」 (기본)
위·아래 끝은 고정되고 가운데가 고무줄처럼 늘었다 줄며 한쪽으로 휘었다가 반대로 넘어갑니다. 이웃 면과 **절대 겹치거나 부딪치지 않도록** 계산합니다(좁아졌다 넓어질 뿐 순서가 유지됨). 박자에는 움찔거리지 않고 부드럽게 한 번 더 부풀기만 합니다.
- 너울: `BPM` · `방향 바뀌는 주기(박)` · `늘었다 줄어드는 주기(박)`·`정도` · `박자 부풂` · `가로 물결 수` · `커브 모양(한 번 휨↔S자)` · `물결 옆 흐름`, 그리고 기존 `커브 춤 정도`(0이면 곧은 직면)·`커브 폭`·`춤 속도`
- **면 하나에 배정될 색상**: `1색`(면 전체가 한 톤으로 머물다 다음 색으로 천천히 바뀜 — 보라→민트, 오렌지→마젠타처럼) · `2색 흐름` · `3색 흐름` · `팔레트 전체 그라데이션(이전 방식)`. 면마다 팔레트에서 서로 다른 색 순서를 배정받아 이웃 면끼리 톤이 겹치지 않습니다. 팔레트는 최대 6색 — 색을 많이 넣을수록 다채로워집니다.
- 컬러: `한 톤에 머무는 정도` · `같은 색 안의 명암 깊이` · `컬러 흐름 속도`(색이 바뀌는 빠르기) · `박자 가속` · `그라데이션 길이` · `면별 흐름 속도 편차` · `반대로 흐르는 면 비율` · `면별 그라데이션 길이 편차` · (`팔레트 전체 그라데이션`일 때) `면별 컬러 분포`
- 구성 예(1_5 프리셋): 뒤에 `커브 춤 정도 0`인 면 레이어(직면에 컬러만 흐름), 위에 커브 춤 정도를 키프레임으로 0→1 올리는 면 레이어.
- 예전 진동 방식은 `세로 면 — 구버전(진동)`.

### 레이어 복사 / 붙여넣기 (씬 사이)
- 레이어 우클릭 → `레이어 복사` / `모든 레이어 복사` / `붙여넣기`. 단축키 **Ctrl+C / Ctrl+V** (키프레임을 선택했을 땐 키프레임 복사).
- 다른 씬 백업을 열고 Ctrl+V 하면 그 씬에 붙습니다. 복사한 레이어는 프로그램을 껐다 켜도 남아 있습니다(큰 이미지·영상 소스는 켜져 있는 동안만).
- 하단 씬 백업 아이콘 우클릭 → `이 씬의 모든 레이어 → 현재 씬에 붙여넣기` 또는 `레이어 하나 골라 가져오기` — 그 씬을 열지 않고 바로 가져옵니다. 레이어가 쓰는 이미지·영상 소스도 함께 옵니다.

## v0.5 추가 기능 — 로봇팔 군무 · 네온 입체 기하 · 레이저 아트 (씬 3_3)

### 로봇팔 군무 레이어 (⊾)
실물 RB20-1900ES 형상(제공 STEP 기반, 117,228 → 6,890 삼각형으로 최적화, 관절 6축 피벗 검증)을 3D로 그립니다. **베이스는 항상 바닥에 고정**되고 움직임은 관절 회전으로만 만듭니다.
- **배치**: 로봇팔 수(1~24) · 배치 방식(일렬/면마다/앞뒤 지그재그/원호/V자/무작위) · 배치 범위 · **위치 X(좌우)·Y(바닥 높이)·Z(앞뒤)** · 앞뒤 간격 · **스케일** · 크기 편차 · 집결(한곳으로 모이기)·집결 위치 · 바라보는 방향·방향 배치 · 뒤쪽 어둡게.
  - **개별 위치**: `번호:x,y,z,스케일; …` 예) `1:0.05,0,0.3,1.2; 4:-0.03,0.02,-0.4` (번호는 왼쪽부터 1).
- **시점**: 방위·높이·원근 강도 (0도 = 정측면, 숙인 실루엣이 가장 잘 보임).
- **움직임(템포)**: 춤 스타일 8종(테크노·EDM·왈츠 3/4·발라드·브레이크 댄스·너울 춤·팝핀·힙합 바운스) · 큐시트 BPM · **동작 속도(느리게↔빠르게, 키프레임 가능)** · 박자 오프셋.
- **동작**: 동작 크기 · 에너지(부드러움↔절도) · **동작 다양성(0 = 통일 군무, 1 = 제각각)** · 위상 흐름(차례로 따라하기)·흐름 방향 · 구부정함.
- **동작 어휘**: 좌우 회전 · 박자 바운스 · 관절 물결 · 손목 꺾기·비틀기 · 원 그리기 · 앞뒤 기울이기 · 포즈 끊어 멈추기 · 크게 돌기. 스타일 기본값에 곱해지는 배율입니다.
- **자세 원칙**: 기본은 구부정한 자세. 팔꿈치가 일정 각도 이상 항상 굽어 있고, 아래팔이 수직으로 서지 않으며, 손목이 바닥을 뚫지 않도록 관절을 제한합니다(위로 곧게 뻗는 동작 최소화).
- **재질**: 원본 플라스틱 / 디지털 네온 / 솔리드 2D / 크롬 메탈 / 홀로그램 와이어. 가장자리 발광·몸체 밝기·불투명도·광택·모서리 라인(두께·번짐·흰 심·투시).
- **색상**: 재질 원색 / 단색 / 로봇마다 / **색 흐름(위치 따라 좌↔우 이동)** / **랜덤 흐름**, 랜덤 움직임 섞기, 관절 캡 색 분리, 박자 발광.
- **반응**: 마커 때 타격 포즈·발광(가까운 면의 로봇일수록 강하게).

### 네온 입체 기하 레이어 (◇)
입방체·정사·팔·십이·이십면체·삼각/육각기둥·사각뿔·다이아몬드와 기하무늬(별·겹 육각·회전 사각·원환·삼각 격자)가 **제자리에서 회전**합니다. 회전 축 X/Y/Z/조합/무작위, 속도·편차·이웃 반대 방향·기본 기울기·흔들림·박자 맥동.
표시 방식: **외곽선만(실루엣) / 보이는 모서리만 / 모든 모서리(투시) / 반투명 면+모서리 / 네온 솔리드**. 그려짐 정도(0→1 드로잉), 안쪽 겹 도형, 꼭짓점 점, 색 흐름·모서리 그라데이션, 마커 회전 킥·팝·발광.

### 레이저 아트 레이어 (⚡)
빛·빔(조명 원뿔)과 별개로 가늘고 강한 레이저 빔. 패턴: 부채꼴 · 평행 스캔 · 교차 X · 위에서 내리꽂기 · 방사 터널 · 라이트 시트 · 가로 확산 빔 · 레이저 그래픽(리사주·원·별·물결·나선·꽃잎).
BPM·움직임 속도·흔들림 각도/주기·광원 간 위상차·회전·순차 점멸(체이스)·스트로브, 빔 심/번짐/흰 심/거리 감쇠/안개 산란/광원 헤드/끝점 맺힘, 색 배치(광원마다·빔마다·흐름), 마커 점멸·펼쳐짐.

### v0.5.1 수정
- **360° 연결 모드에서 화면이 세로로 뚝 잘려 보이던 문제 해결**: 레이저·빛빔 모두 이웃 광원 위치까지 함께 계산해 끊김 없이 이어집니다.
- **레이저 끝 처리**: `끝부분 페이드`(기본 45%)로 끝쪽이 서서히 투명해지며 사라집니다(0이면 칼처럼 끊김). `빔 길이 편차`(기본 30%)로 빔마다 길이가 달라 끝이 한 줄로 맞춰지지 않습니다.

### 프리셋: 「씬 3_3」 (40초, 128 BPM)
0–10초 EDM 군무 시작 + 세 포인트 레이저 → 10–20초 위에서 내리꽂는 레이저 + 디지털 기하 패턴 → 20–30초 공간 전체로 확산되는 가로 레이저 파장 → 30–40초 스모그·레이저·네온 입방체·군무 결합(카타르시스). 동작 다양성·속도·위상 흐름이 막마다 키프레임으로 바뀝니다.

## v0.4 추가 기능

- **메뉴 막대**(파일·편집·보기·옵션·도움말). 도움말 → 사용법/단축키(F1).
- **되돌리기** Ctrl+Z 최대 10단계, **다시 실행** Ctrl+Y(또는 Ctrl+Shift+Z). 레이어 추가·삭제·프리셋·씬 불러오기도 되돌릴 수 있습니다.
- **씬 백업(Ctrl+S)**: 현재 상태가 화면 맨 아래 줄에 썸네일 아이콘으로 쌓입니다. 클릭하면 그 씬을 불러오고, PageUp/PageDown으로 순서대로 넘겨볼 수 있습니다. 우클릭: 덮어쓰기·이름·순서 이동·삭제. Ctrl+Alt+S = 활성 씬 덮어쓰기.
- **액트 저장/열기**: 하단 줄의 모든 씬을 하나의 `.rlab-act.json`으로 저장 → 다른 PC에서 열어 액트 전체를 순서대로 클릭하며 검토. (프로젝트 1개 파일 저장은 Ctrl+Shift+S)
- **자동 보관**: 액트 열기로 씬 백업을 바꾸거나 모두 지우면 직전 상태가 자동 보관됩니다. 데스크톱 앱은 옵션 → `자동 보관 폴더 열기`(최근 30개, 액트 열기로 되돌림), 브라우저는 직전 1개만 브라우저 저장소에 남습니다.
- **패널 크기 조절**: 좌·우 패널 경계, 타임라인 위 경계를 드래그(더블클릭=기본값). 크기는 자동 기억.
- **미리보기 확대/축소**: 마우스 휠(커서 중심), 휠버튼 또는 Alt+드래그로 이동, 더블클릭 = 맞춤, Ctrl+1 = 출력 1:1.
- **360° 좌우 연결**(상단 토글 / 옵션 메뉴): 켜면 모든 레이어가 좌우 끝에서 이음새 없이 이어집니다. '이음새 확인'으로 화면을 반 바퀴 돌려 경계를 검수.
- **레이어 합성 10종**: 일반·더하기·스크린·곱하기·하드라이트·오버레이·소프트라이트·차이·밝게·어둡게.
- **라인 재질**: 네온/튜브(입체 원통)/리본/붓/평면/구슬, 그림자(거리·번짐), 시간 잔상(개수·간격·감쇠·밀림), 색 배치(선마다/가로 그라데이션/깊이).
- **도트 돌출 각도(3D)**: '돌출 방향'(0=위, 90=오른쪽, ±180=아래로 튕김), 'Z축 기울기'(90=관객 쪽으로 튀어나옴, −90=화면 안쪽으로 꺼짐), Z 원근 강도·소실점(없음/면마다/화면 중앙)·소실점 높이, '반대쪽으로도 튕김', 타격 방향(밀기/꺼트리기/번갈아). 모두 키프레임으로 회전 가능.
- **도트 높이에 따른 크기 변화**: +면 솟은 도트가 커지고 −면 작아짐, '크기 변화 곡선'으로 꼭대기에서만 변하게 조절.
- **파동 가로선(스윕) 토글**: 파장 레이어의 '가로선 파장(아래→위)'은 이제 기본 꺼짐이며, 켜면 타격 때 가로선 파장이 아래에서 위로 한 번 훑고 지나갑니다.
- **파장 상하단 열림**: 화면 위·아래 경계에서 파장이 반사되지 않고 화면 밖으로 빠져나가도록 흡수 경계를 강화했습니다.
- **타임라인 키프레임 편집**: 하단 타임라인에서 키프레임을 드래그로 이동, 빈 곳 드래그로 사각형 다중 선택(Shift 추가), 더블클릭·우클릭으로 삭제, Delete로 선택 삭제, Ctrl+C/Ctrl+V로 복사·재생헤드 위치 붙여넣기.
- **글로우 경계선 제거**: 오브젝트·이펙트의 빛(글로우)이 칸 경계를 넘어가며 네모나게 잘려 보이던 현상을 없앴습니다. 빛이 사각형 테두리 없이 부드럽게 사라집니다.
- **도트 '해수면 표면' 배열**: 도트 레이어 배열을 사각/육각 격자 대신 '해수면 표면'으로 바꾸면, 원근으로 수평선에 모이는 도트 바다가 완만히 일렁이고 윤슬(반짝임)이 흐릅니다. 잔물결 높이·흐름 속도·윤슬·수평선 원근·먼 곳 흐려짐 조절. (달·밤하늘은 렌더하지 않음)
- **파장 '발광 링(빛 파장)' 모드(기본)**: 중심에 광원이 남지 않고, 밝은 동심원 링이 바깥으로 퍼져나가는 빛의 파장. 지속 발광(0 펄스↔1 상시 오브)·링 확산 범위·소용돌이·반짝임 입자 조절. 벽 반사·왜곡 없이 화면 밖까지 확산.
- **파장 상하 확산 보강**: 시뮬을 화면보다 넓은 영역에서 계산해, 링이 찌그러지지 않고 깨끗한 원으로 화면 밖까지 나갑니다.
- **가로지르기(라인) 자연화**: 시작·끝 면 '안쪽 랜덤 위치'에서 출발/도달하고, 끝에 닿으면 광채 머리가 부드럽게 페이드아웃(도착 머리 페이드 슬라이더). 면 경계 줄맺힘이 사라집니다.
- **선 두께 편차·흐름 싱크 슬라이더**: 선마다 두께를 무작위 가감, 흐름 싱크(0 따로↔1 통일)로 하나의 중심 운동에 다중선을 밀집.
- **선운동 스크래치**: 기존 '낙하 스크래치'를 확장 — 흐름 방향(아래/위/좌/우)·퍼짐 범위로 가로·세로 모든 흐름 제어.
- **모드별 슬라이더 잠금**: 현재 모드에서 안 쓰는 슬라이더는 회색으로 잠겨 보기 편합니다.
- **키프레임 자석 스냅**: 키프레임을 Shift+드래그하면 다른 키프레임·마커·재생헤드에 딱 붙습니다(AE 방식).
- **파장 개선**: 벽에 부딪혀 되돌아오는 반사(불필요)를 없애 열린 공간처럼 퍼져 사라지고, 표현에 '소프트 글로우 링'(빛나는 동심원)과 '간섭 광망'을 추가했습니다. 시뮬 해상도 기본값도 높였습니다.
- **슬라이더 입력 수정**: 재생 중에도 수치 칸에 키보드로 값을 입력할 수 있고(입력 중 값이 지워지지 않음), Enter로 바로 적용됩니다.
- **파티클**: '상시 방출'과 '마커 때 폭발'을 각각 켜고 끄는 체크박스.
- **리듬게임 레이어**: 고정 심벌(기본 베이스 기타 라인아트) · 떨어지는 노트 · 타격 이펙트. 노트는 마커 시점에 정확히 심벌에 닿고 그때 이펙트가 터지며, 타격이 쌓일수록 심벌이 밝고 화려해집니다. **노트 도착 싱크 / 이펙트 터짐 싱크**(ms) 슬라이더 별도, 심벌·노트·이펙트 표시 체크박스, 각 요소를 이미지·짧은 영상으로 교체 가능.
- **오브젝트 유영 레이어**: 화면 아래 바깥에서 떠올라 위로 빠져나가는 오브젝트(기본: 징·북·장구·꽹과리·기타). 부력·중력·저항·좌우 운동 폭/빈도·바람·회전·원근감·서로 부딪힘, 마커마다 **터지는 비율(일부↔전체)**만큼 팡 터짐. 이미지/영상 여러 개 첨부.
- **이미지·영상 첨부**: PNG/JPG는 최대 768px로, MP4/WebM은 최대 48프레임 아틀라스로 변환해 프로젝트 파일 안에 함께 저장(다른 PC에서도 그대로 열림). 영상은 기본 '검정=투명' — 버튼으로 원본 알파로 전환.
- 프리셋 추가: 「리듬게임 인게임 — 베이스 심벌」, 「오브젝트 유영 — 악기 상승·팡」.
- 수정: 면(그라데이션 흐름) 레이어와 파장 '스윕' 마커가 두 번째 재생/출력부터 미세하게 달라지던 문제(결정적 렌더 깨짐)를 고쳤습니다.

## 알아둘 점

- **결정적 렌더**: 같은 프로젝트 + 같은 Seed = 같은 프레임(검증 완료). 수정 후 다시 뽑아도 같은 결과입니다.
- 정지 상태에서 움직임 관련 값을 바꾸면 현재 프레임까지 자동으로 다시 계산합니다(긴 위치에서는 수 초 걸릴 수 있음).
- PNG 시퀀스는 폴더를 선택해 바로 저장합니다(Chrome/Edge). 폴더 선택이 안 되는 환경은 ZIP으로 내려받습니다. 렌더 설정 JSON이 함께 저장됩니다.
- 프로젝트는 브라우저에 자동 저장되며, 「저장」으로 `.rlab.json` 파일을 내려받아 보관·공유합니다.
- MP4는 알파를 지원하지 않습니다. 합성용 소스는 PNG 시퀀스를 쓰세요.
- 내부 색 계산은 sRGB 기준입니다(v0.2에서 linear 작업 공간 검토).
