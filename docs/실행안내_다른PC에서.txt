RESONANCE LAB — 다른 PC/다른 위치에서 실행하기

[가장 간단한 방법] RESONANCE_LAB_v0.5.7_portable.exe (Releases에서 받기)  (파일 1개)
  - 이 exe 하나만 USB·메일·공유폴더로 옮겨 더블클릭하면 됩니다. 설치 필요 없음.
  - 실행할 때마다 임시 폴더에 풀어서 켜지므로 첫 실행은 5~15초 걸릴 수 있습니다.

[폴더 방식] RESONANCE_LAB_Desktop 폴더
  - "RESONANCE LAB.exe" 파일만 복사하면 실행되지 않습니다. 폴더 전체(resources, locales, *.dll, *.pak 포함)를 통째로 복사하세요.
  - ZIP으로 옮겼다면: ZIP 파일 우클릭 → 속성 → 아래쪽 「차단 해제」 체크 → 확인 → 그 다음 압축 풀기.
    (인터넷/메신저로 받은 ZIP은 Windows가 차단 표시를 붙여 dll 로딩이 막힐 수 있습니다)
  - ZIP 안에서 바로 더블클릭하지 말고 반드시 압축을 푼 뒤 실행하세요.

[처음 실행 시 파란 경고창 「Windows의 PC 보호」가 뜨면]
  - 「추가 정보」 → 「실행」을 누릅니다. (코드 서명이 없는 프로그램이라 뜨는 경고입니다)
  - 회사 보안 프로그램(V3, 알약 등)이 막으면 예외(허용) 목록에 추가하세요.

[실행은 되는데 화면이 까맣거나 "WebGL2를 사용할 수 없습니다"가 뜨면]
  - 그래픽 가속(GPU)이 없거나 막힌 PC(원격 데스크톱, 가상 PC, 오래된 내장 그래픽)입니다.
  - 화면의 「호환 모드(소프트웨어 렌더링)로 다시 시작」 버튼을 누르세요. 느리지만 대부분의 PC에서 동작합니다.
  - 정상 PC로 돌아가려면: 옵션 메뉴 → 「GPU 호환 모드 — 다시 시작」 체크 해제.

[실행 조건]
  - Windows 10 / 11 64비트. (Windows 7·8, 32비트 Windows에서는 실행되지 않습니다)

[그래도 안 될 때 — 아래 로그 파일을 보내 주세요]
  - %APPDATA%\RESONANCE LAB\startup.log
    (파일 탐색기 주소창에 %APPDATA%\RESONANCE LAB 입력)

[작업 데이터 옮기기]
  - 씬 백업(하단 아이콘)과 자동 저장은 PC마다 따로 저장됩니다.
  - 다른 PC로 옮기려면: 하단 「액트 저장」(.rlab-act.json) 또는 Ctrl+Shift+S(프로젝트 파일)로 저장 → 다른 PC에서 「액트 열기」/「열기」.
